# snapsync MVP Roadmap

## Phase 1

- Recursive folder scan
- ExifTool metadata extraction
- Filename normalization
- Folder creation
- Copy workflow
- Media classification
- Summary reporting
- Colored logs
- Dry-run audit mode

## Phase 2

- SQLite index
- Faster duplicate lookup
- Resume interrupted runs
- Configurable rules
- Persistent run history

## Phase 3

- Device auto-discovery
- Wi-Fi sync
- Live monitoring
- UI application
- macOS menu bar app

## Phase 4

- iPhone companion app
- Background sync
- AI duplicate grouping
- Face/event clustering
- Smart album generation
